# Адвент-календарь

Статический сайт на HTML + CSS + JavaScript для GitHub Pages.

## Параметры

- 12 окошек
- старт: 30 сентября 2026, 12:00
- часовой пояс: UTC+7
- интервал: 1 час
- первое окошко: 12:00
- последнее окошко: 23:00
- Material Design-подобный интерфейс
- адаптивная мобильная версия
- countdown до следующего окошка
- localStorage для запоминания открытых окошек
- текст, изображения, видео и ссылки
- без backend

## Запуск локально

Можно просто открыть `index.html` в браузере.

Для более корректной проверки локально удобно использовать любой простой HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Изменение содержимого

Все тексты находятся в:

`content/days.js`

Пример:

```js
{
  day: 1,
  title: "Мой заголовок",
  text: [
    "Первый абзац.",
    "Второй абзац."
  ],
  image: "images/day-01.jpg",
  imageAlt: "Описание изображения"
}
```

Видео:

```js
{
  day: 2,
  title: "Видео дня",
  text: "Описание видео.",
  video: "videos/day-02.mp4"
}
```

Ссылка:

```js
{
  day: 3,
  title: "Ссылка",
  text: "Дополнительный материал.",
  link: {
    label: "Открыть",
    url: "https://example.com"
  }
}
```

## Добавление изображений и видео

Положите файлы в папки:

- `images/`
- `videos/`

и укажите относительный путь в `content/days.js`.

Для GitHub Pages рекомендуется оптимизировать изображения и не хранить большие видеофайлы непосредственно в репозитории.

## GitHub Pages

1. Создайте новый GitHub repository.
2. Загрузите все файлы проекта.
3. Откройте `Settings` → `Pages`.
4. В разделе публикации выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки.
7. GitHub Pages выдаст адрес сайта.

## Важно про время

Внутри JavaScript старт задан как UTC-время:

`2026-09-30T05:00:00.000Z`

Это соответствует 12:00 в UTC+7.

Для отображения UTC+7 используется часовой пояс `Asia/Bangkok`, который имеет постоянное смещение UTC+7 и не использует переход на летнее время.

## Ограничение статического сайта

Время проверяется в браузере пользователя. Поэтому технически пользователь может изменить системные часы и открыть будущие окошки раньше.

Также весь контент, находящийся в репозитории GitHub Pages, потенциально доступен пользователю напрямую. Если требуется реальная защита будущего контента, нужен backend/API.
